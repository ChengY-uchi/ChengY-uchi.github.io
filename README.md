# Cheng Yang — Academic Homepage

Personal academic website for PhD applications, published with GitHub Pages.

## Edit the site

- `index.html`: biography, research interests, publications, experience, and links
- `styles.css`: typography, colors, layout, and responsive design
- `script.js`: reveal animation and footer year
- `assets/`: profile photo, CV, publication teasers, and other downloadable files

## Replace before public launch

1. Replace every `your-email@domain.edu` in `index.html`.
2. Add `assets/profile.jpg` and replace the portrait placeholder with an image.
3. Add `assets/Cheng_Yang_CV.pdf` and update the CV link.
4. Replace the Google Scholar placeholder link.
5. Replace each publication placeholder with its title, authors, venue, description, links, and teaser image.

## Publish

In the repository, open **Settings → Pages** and select:

- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/ (root)**

Every push to `main` will update the site at `https://chengy-uchi.github.io`.
